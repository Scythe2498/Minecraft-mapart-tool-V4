ImageToMapMC 1.10.0 - modified (v4)

Just double-click mcmap-gui.exe. Nothing to install.

NEW: 3D STACKED CARPETS
  Build Method menu > "3D Stacked Carpets" (last item)
  - Uses only the 16 carpet colors, in all 3 shades (48 colors instead of 16).
  - Every carpet stands on a column of the same carpet, all the way down to your
    platform. No stone, no air gaps - just place it on your obsidian.
  - Stacks are kept as low as the shading allows, to save carpets.
  - The north edge row (needed for 3D shading) is white carpet.
  - Support block settings are ignored in this mode (carpets support themselves).
  - The materials list counts every carpet, exactly as exported.
  Tip: this uses a LOT of carpets. A busy 512 x 512 image can need ~2 million.

ONE-LAYER FLAT MAP ART
  Build Method > Flat, then Materials > Support blocks options >
  tick "No support blocks". Export = exactly one layer.

3D / STAIRCASE, SINGLE FILE
  "Export as a single schematic/structure file" lays maps out as a square grid,
  with heights lined up across map edges so the shading is exact.

LITEMATICA TIPS
  - Exact material count for any size: M > Load Schematics > pick file > "Material List".
  - Flat maps are 1 layer: if nothing shows, check the Render Layers setting (set to All).

Windows may show "Windows protected your PC" the first time (unsigned build).
Click "More info" then "Run anyway".
